# C Programming Projects

A collection of C programs I built while learning systems programming.

## 🧠 Skills Demonstrated
- Variables, loops, and conditionals
- Arrays, strings, and memory layout
- Functions and modular programming
- Structures (`struct`) and data organization
- Input validation and buffer overflow protection
- Console-based menu interfaces

## 📁 Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | `calculator.c` | Basic arithmetic calculator using `switch` logic |
| 2 | `guessing_game.c` | Number guessing game with attempt counter and random seeding |
| 3 | `mpesa.c` | M-PESA mobile money simulation with nested transactions and PIN verification |
| 4 | `personal_info_card.c` | Input/output formatting using basic structures |
| 5 | `student_grade_tracker.c` | Multi-student mark tracker with averages and letter grades |
| 6 | `contacts_manager.c` | Contact book supporting add, search, and delete operations |
| 7 | `product_inventory.c` | Stock manager tracking total valuation, max, and min items |
| 8 | `employee_salary.c` | Payroll recorder computing aggregate totals and top earners |
| 9 | `movie_collection.c` | Interactive movie database filtered by ratings and genres |
