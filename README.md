# C Programming Projects

A collection of C programs I built while learning systems programming.

## 🧠 Skills Demonstrated
- Variables, loops, conditionals
- Arrays and strings
- Functions and modular programming
- Structures and data organization
- Input validation and error handling
- Menu-driven interfaces

## 📁 Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | `calculator.c` | Basic calculator with menu and switch |
| 2 | `guessing_game.c` | Number guessing game with attempts counter |
| 3 | `mpesa.c` | M-PESA menu simulation with nested switches |
| 4 | `personal_info_card.c` | Simple input/output program |
| 5 | `student_grade_tracker.c` | Stores marks, calculates averages and grades |
| 6 | `contacts_manager.c` | Add, search, delete contacts using arrays |
| 7 | `product_inventory.c` | Track products, total value, highest/lowest |
| 8 | `employee_salary.c` | Employee records, total salary, highest paid |
| 9 | `movie_collection.c` | Movie database with rating and genre filter |
